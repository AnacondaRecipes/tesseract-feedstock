## Summary

This is a significant feature and maintenance release spanning three minor versions (5.2.0 → 5.5.2) with approximately 250 commits. It includes new features (PAGE XML renderer, RISC-V V SIMD support, C++ stream logging), removal of deprecated functionality (OpenCL support, TensorFlow support), major internal refactoring (CLIST/ELIST templating, tprintf modernization), numerous bug fixes (FP exceptions, colormap handling, ALTO XML duplicate IDs, Conda datadir setup), compiler warning cleanups, and CI/build system improvements. The C++ standard has been bumped from C++11 to C++17.

## Dependency changes

- **TensorFlow support removed** entirely (no longer a dependency)
- **OpenCL support removed** entirely (no longer a dependency)
- **C++17 is now required** (previously C++11 was sufficient for some build paths)
- CMake minimum requirements adjusted; cmake >= 3.30 recommended for OpenMP warning suppression
- Build CI updated to use Ubuntu 24.04 with GCC 14 (previously Ubuntu 20.04 with GCC 9)
- `googletest` submodule updated to v1.15.2
- macOS CI updated to require `libtool`, `libarchive`, `pango`, `icu4c`, `curl`
- Windows installer: updated libpng and libtiff versions
- `GNUInstallDirs` now used more consistently for `CMAKE_INSTALL_LIBDIR`

## API / ABI changes

- **OpenCL API functions removed** — public API functions related to OpenCL have been deleted; downstream packages using those functions will break
- **New PAGE XML renderer functions added** to the C API (new symbols, backward-compatible additions)
- `Network::spec()` made pure virtual — affects ABI for subclasses
- SOVERSION now correctly set based on SemVer properties (may change the `.so` version number)
- New `tesserr` C++ stream exported with `TESS_API`
- `tprintf()` signature changed (mandatory format argument, conversion from va_args style)
- CLIST/ELIST internalized as templates — internal ABI change; affects any code using these internal classes directly
- `--oem` and `--psm` now support symbolic string values (backward-compatible CLI change)
- New `-c` parameter handling improvements

## Security-relevant changes

- Fixed several uninitialized variable issues (CID reports from Coverity)
- Fixed floating-point overflow in `NormEvidenceOf` (issue #4257)
- Fixed FP exception in `Wordrec::angle_change` (issue #4242)
- Replaced `strcpy`/`strncpy` with safer inline helper
- Replaced `access()`/`_access()` with `std::filesystem::exists()`
- Wrapped `main()` in try/catch for better exception safety
- Fixed invalid empty interval in `punct_stripped()` for all-punctuation words

## Platform / build system changes

- **C++17 now required** (was C++11)
- CMake updated to use `target_compile_features` instead of `set_property`
- `GNUInstallDirs` / `CMAKE_INSTALL_LIBDIR` used consistently
- SOVERSION correctly derived from semantic version
- MSVC: PDB files installed (debug symbols); static library PDB excluded
- `CMAKE_BUILD_TYPE` changed from `Release` to `RelWithDebInfo` in CI
- Ubuntu CI upgraded from 20.04/GCC-9 to 24.04/GCC-14
- macOS CI upgraded from macOS-11/12 to macOS-14/latest
- Windows CI upgraded from windows-2019 to windows-latest
- RISC-V V (vector extension) SIMD support added
- NSIS Windows installer script added
- Removed use of `GLOB` in CMake files (fixes #4442)
- TensorFlow build support removed (`src/lstm/tfnetwork.cpp` now conditionally compiled, then TF removed entirely)
- OpenCL build support removed

## Recipe update risk

**MEDIUM-HIGH**

The removal of OpenCL and TensorFlow dependencies, the C++17 requirement, updated SOVERSION semantics, and `GNUInstallDirs` changes all require recipe review; any conda recipe that enabled OpenCL or TF support, pinned the `.so` version, or set C++ standard flags will need editing, and the new PAGE XML renderer adds new exported symbols to verify.
